在 AI 应用中，这两个词主要解决两个问题：

> **评测：AI 做得好不好？**  
> **可观测性：AI 为什么做成这样？**

### 评测（Evaluation）

用一组标准和测试数据衡量 AI 输出质量，包括：

- 回答是否正确、相关
- 是否出现幻觉
- RAG 是否检索到正确资料
- Agent 是否选对工具、完成任务
- 输出是否安全、合规
- 响应速度和调用成本是否达标

例如用户问“公司年假有几天”，系统需要判断：

- 是否找到了正确制度文档
- 回答是否忠于文档
- 有没有编造不存在的规定

### 可观测性（Observability）

记录并追踪 AI 应用实际运行的全过程，以便定位问题，包括：

- 使用了哪个 Prompt 和模型
- RAG 检索到了哪些文档
- Agent 调用了哪些工具
- 每一步输入和输出是什么
- Token、延迟、成本、错误率
- 问题发生在检索、模型还是工具调用环节

例如 Agent 回答错误，可以通过运行链路判断：

```text
用户问题
  → 意图识别
  → RAG 检索
  → 模型推理
  → 工具调用
  → 最终回答
```

究竟是哪一步出了问题。

### 在图中如何表达

如果面向技术人员，保留：

> **评测 · 可观测性**

是准确且专业的。

如果面向普通读者，可以换成更直白的：

> **效果评估 · 运行监控**

或者：

> **质量评估 · 全链路追踪**

其中我最推荐 **“效果评估 · 运行监控”**，阅读门槛更低，也最容易理解。
