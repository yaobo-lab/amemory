# 《DHCP还是静态IP？网络模式怎么选》—— 学习笔记

> 场景引入：200台IP话机入网，选DHCP（省事但IP可能变、排查难）还是静态IP（稳定但逐台配置工作量大）？这是几乎所有VoIP部署都会遇到的两难选择。

---

## 一、DHCP：自动分配IP的"快递派件员"

**定义**：DHCP（Dynamic Host Configuration Protocol，动态主机配置协议）——设备插上网线，服务器自动配好 IP地址、子网掩码、网关、DNS，无需人工干预。

**类比**：酒店前台。你进酒店（设备入网），前台直接给钥匙（IP）、房间号（IP）、楼层（子网）、出口（网关）、前台电话（DNS）。

**DHCP分配的关键信息**：IP地址、子网掩码、默认网关、DNS服务器、租期；还可额外下发 **DHCP Option**（如SIP服务器地址、TFTP服务器地址）——这正是 **VoIP零配置部署的核心**。

### 1.1 DHCP工作流程：DORA 四步

```
 DHCP客户端                DHCP服务器
 (IP话机/PC)              (路由器/专用服务器)
      │                         │
      │─ 1. Discover (发现) ───▶│  广播"有人在吗？"
      │   源IP:0.0.0.0  目标:255.255.255.255  UDP 67
      │                         │
      │◀── 2. Offer (提供) ─────│  "我这有IP给你用"
      │   如: 192.168.1.100/24, 网关192.168.1.1
      │                         │
      │─ 3. Request (请求) ────▶│  "我要这个IP！"(仍为广播)
      │   确认选 192.168.1.100
      │                         │
      │◀── 4. Ack (确认) ───────│  "确认，归你了！"
      │   含 IP/掩码/网关/DNS/租期/Option
```

**关键细节**：
- Discover 和 Request 都是**广播**（目标255.255.255.255），确保全网DHCP服务器都能收到
- 多个服务器回应Offer时，客户端**只接受第一个**收到的
- IP有**租期**（默认8天），到期前需续租：T1=50%租期时单播续租，T2=87.5%时广播续租

**生活类比**：新员工入职——行政（DHCP服务器）直接告诉你工位（IP）、进哪个门（网关）、前台电话（DNS）、工牌有效期（租期），你只需说一句"我来了"（Discover）。

## 二、静态IP：手动配置的"固定门牌号"

**定义**：管理员手动给每台设备指定固定IP，填好掩码、网关、DNS，地址**永久不变**（除非人为修改）。不依赖DHCP服务器，开机即可通信；但须人工逐台配置并做好记录，防止IP冲突。

**举例（SIP服务器）**：
```
IP地址: 192.168.1.10 / 掩码: 255.255.255.0 / 网关: 192.168.1.1 / DNS: 8.8.8.8
```
写死在配置里，重启、断电、换网线都不变。

**核心特征**：地址固定不变、不依赖DHCP、需人工维护IP分配表、适合数量少且稳定性要求高的设备。

## 三、DHCP vs 静态IP：全方位对比

```
 ┌─────────── DHCP模式(自动获取) ───────────┐   ┌─────────── 静态IP模式(手动配置) ──────────┐
 │ 话机A    话机B    话机C    话机D          │   │ 话机A.101 话机B.102 话机C.103 话机D.104   │
 │ (自动获取 ×4)                             │   │ (逐台手动填写)                            │
 │      └──────┬─────────┘                   │   │      └──────┬─────────┘                 │
 │          交换机 (二层透传,不参与IP分配)     │   │          交换机 (二层透传)               │
 │               │                           │   │               │                         │
 │     DHCP服务器(路由器内置)                 │   │        网关路由器                        │
 │     地址池:192.168.1.100~200              │   │        仅做路由,不分配IP                   │
 │     分配IP+网关+DNS+Option                │   │        网关:192.168.1.1                  │
 │ 配置: 选DHCP→插网线→自动完成(即插即用)     │   │ 配置: 逐台登录Web→手动填参→登记IP分配表   │
 └───────────────────────────────────────────┘   └───────────────────────────────────────────┘
```

| 对比项 | DHCP（动态） | 静态IP（固定） |
|---|---|---|
| 配置方式 | 服务器自动分配 | 逐台手动填写 |
| 部署效率 | 高，即插即用 | 低，量大费时费力 |
| IP稳定性 | 租期内稳定，到期可能变化 | 永久固定 |
| IP冲突风险 | 低（服务器统一管理） | 中（人为失误可能冲突） |
| 故障排查 | 较难（IP可能变动） | 容易（IP固定一目了然） |
| 额外能力 | 可下发Option（SIP/TFTP地址） | 无 |
| 依赖DHCP服务器 | 是（宕机则新设备无法入网） | 否（独立工作） |
| 适合设备 | 大量终端话机、PC、移动设备 | 服务器、网关、少量关键设备 |

## 四、DHCP租期：IP不是永久给你的

IP是"租借"不是"赠送"，默认租期通常 **8天**（可改）。到期不续租，IP被收回重新入池。

```
 租期生命周期 (默认8天 = 192小时)
 |---------------- 96h(50%) ---------------|--- 168h(87.5%) ---|- 192h(100%)
 [   正常使用期      ][    T1 续租期       ][ T2 重绑定期      ][到期]
  IP可用,无需操作     单播向原服务器续租      广播向任意服务器续租   IP释放
```

**续租失败的结果**：
- T1成功 → 租期重置为8天
- T1失败、T2成功 → 租期重置，但记录了新DHCP服务器
- T1/T2都失败、到期 → 释放IP，重新走DORA获取新IP
- **对VoIP的影响**：IP释放期间通话中断，进行中的通话会掉线

**举例**（租期8天，周一获得 192.168.1.100）：
- 周四（T1，50%）：单播续租 → 成功 → 租期重置
- 若周四无回应，周日（T2，87.5%）：改为广播续租，任意服务器可回应
- 若周日也无回应，下周一（100%）：IP释放，重新走DORA

**VoIP注意事项**：DHCP服务器不可用时，话机到期IP被释放 → 通话掉线 + 失去IP无法注册。故VoIP环境中DHCP服务器稳定性至关重要，建议 **DHCP冗余** 或 **缩短租期** 以便快速发现故障。

## 五、VoIP场景怎么选？决策图

核心看两个维度：**设备类型** 和 **设备数量**。

```
                    ┌──────────────────┐
                    │ 开始: 新设备入网  │
                    └────────┬─────────┘
                             ▼
                    设备类型是什么?
                   (话机终端/核心服务器)
                    │              │
        ┌── 话机终端 ┘              └─ 核心服务器 ──┐
        ▼                                          ▼
   数量多少?                              ┌────────────────┐
 (≤10 / >10)                              │ 推荐: 静态IP    │
   │        │                             │ SIP服务器/网关/中继│
 少量       大量                           └────────────────┘
   ▼        ▼
 可任选   推荐: DHCP
(静态便于  + DHCP Option
  排查)
   │        │
   ▼        ▼              ┌─────────────────────┐
┌────────┐ ┌────────────┐  │ 核心服务器(静态)      │
│少量话机 │ │大量话机     │  │ IP固定不变           │
│(静态)  │ │(DHCP)      │  │ 话机注册地址稳定      │
│逐台配IP│ │Option66:TFTP│  │ DNS也可,但IP更直接   │
│维护分配│ │Option120:SIP│  └─────────────────────┘
│表,便于 │ │零配置批量部署│
│ 定位   │ └────────────┘
└────────┘
```

**三条选型原则**：
1. **核心服务器 → 静态IP**：SIP服务器、网关、中继等关键设备，IP必须固定，话机才能稳定注册
2. **大量话机 → DHCP + Option**：几十上百台，零配置批量部署，配合Option下发SIP/TFTP地址
3. **少量话机 → 两者皆可**：10台以下，静态IP便于排查；想省事可用 DHCP + 地址保留

## 六、DHCP Option：话机零配置部署的秘密武器

DHCP在分配IP的同时，通过 **Option字段** 把SIP服务器地址、配置文件下载地址一起下发 → 话机开箱、插线、通电即自动完成"获取IP → 下载配置 → 注册SIP"，全程零人工输入，即 **零配置部署（Zero Touch Provisioning）**。

```
 ┌─────────┐  DORA   ┌──────────────┐      ┌──────────────────┐
 │ IP话机   │ ──────▶ │ DHCP服务器    │ ───▶ │ TFTP/HTTP服务器   │
 │ 新机开箱 │         │ 分配IP/网关/DNS│      │ (配置文件/固件)   │
 │ 插网线   │         │ + 下发Option  │ ───▶ │ SIP服务器        │
 │ 零配置   │         └──────────────┘      │ (注册/呼叫处理)   │
 └─────────┘                               └──────────────────┘
```

**常用Option详解**：

| Option | 值 | 作用 | 场景/优势 |
|---|---|---|---|
| **Option 66**（TFTP Server Name） | TFTP服务器地址，如 192.168.1.10 | 话机从此下载配置文件（分机号、SIP密码、功能按键等） | Yealink/Fanvil/Grandstream 等都支持 |
| **Option 120**（SIP Servers） | SIP服务器地址列表，如 sip.example.com:5060 | 话机直接获取SIP注册服务器地址，无需手动配置 | 配合Option 66，"开机即注册"，真正零配置 |
| **Option 150**（TFTP Server Address - Cisco） | 与Option 66类似，但用IP地址格式 | Cisco私有扩展 | Cisco设备 |

**零配置部署全流程**：
```
1. 话机出厂默认DHCP模式，插网线上电
2. DHCP回应Ack，携带 IP=192.168.1.100 + Option66=192.168.1.10 + Option120=sip.company.com
3. 话机向 192.168.1.10 (TFTP) 请求配置文件 → 获取分机号、SIP密码
4. 话机向 sip.company.com (SIP服务器) 发起注册
5. 注册成功 → 正常拨打/接听 —— 全程零人工配置
```

## 七、最佳实践：鱼和熊掌兼得 —— DHCP地址保留

**DHCP Reservation（MAC-IP绑定）**：
- **原理**：在DHCP服务器上把每台话机的 **MAC地址绑定固定IP**。话机仍走DORA流程，但每次都拿到同一个IP
- **效果**：话机端"零配置"（走DHCP），服务器端"IP固定"（MAC绑定），兼得批量部署便利 + 静态IP稳定，还能通过Option下发SIP/TFTP地址

**配置示例**：
```
MAC 00:1A:2B:3C:4D:5E  →  绑定IP 192.168.1.101
每次DHCP获取都拿到 .101，不会变；同时下发Option 66/120
```

**实操建议（黄金组合）**：
```
 核心服务器  →  静态IP
 话机        →  DHCP + 地址保留 + Option
 ─────────────────────────────────
 关键设备稳定 + 话机零配置批量部署 + IP固定便于排查
 中小型项目(10~200台话机)尤其推荐
```
