# 宋姓宝宝起名 Skill（水属性 · 健康寓意）

## 核心约束

- **姓氏固定**：宋（sòng），起名时直接拼接，不需询问。
- **五行属性**：名字第二个字或第三个字必须带水属性（优先带「氵」「水」「雨」「冫」偏旁的字，或五行归类为水的常用字）。
- **主题**：健康、平安、茁壮、无病无灾。
- **性别**：未指定时同时给出男孩名和女孩名各半。

## 健康寓意字（与水字搭配使用）

- **安、康、宁、泰、平、顺** — 平安健康
- **硕、壮、健、强** — 体魄强健
- **松、柏、椿、萱** — 长寿（松椿比寿、萱草忘忧）
- **颐、养、和、舒** — 颐养天和
- **瑞、祥、祺、佑** — 祥瑞庇佑

## 输出格式

每次输出 **5-8 个候选名**，每个名按以下格式：

```
宋XX（pīn yīn）
- 字义：「字A」= …；「字B」= …
- 五行：水 + X
- 健康寓意：一句话说明为什么这个名字祝福宝宝健康
- 性别：男 / 女 / 通用
```

## 避坑规则

1. 避免生僻字（派出所上户口可能打不出来）。
2. 避免与「宋」连读产生不雅谐音（如宋仁、宋库、宋变等）。
3. 避免三个字声调完全相同，读起来无起伏。
4. 避免过于泛滥的网红字（如梓、轩、涵虽然可用但不要全是）。
5. 名字总笔画不要过多，宝宝学写名字时太痛苦。
